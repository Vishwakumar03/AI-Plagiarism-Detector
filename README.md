# AI-Powered Plagiarism Detector

This project is an AI-powered plagiarism detection tool built using Python, Streamlit, and Generative AI.

## Features
- Detects plagiarism using TF-IDF and cosine similarity
- Finds matching sources using Google Search API
- Uses Generative AI for enhanced analysis
- Interactive UI built with Streamlit

## Tech Stack
- Python
- Streamlit
- Google Generative AI (Gemini)
- Scikit-learn
- Google Custom Search API

## How to Run
1. Install dependencies:
   pip install -r requirements.txt

2. Run the app:
   streamlit run app.py

## Note
API keys are required for full functionality.
